## INSTALLATION (3 Steps, 15 minutes)

### STEP 1: Download
```
URL: https://trac.osgeo.org/osgeo4w/
File: osgeo4w-setup-x86_64.exe (click link)
Save: Downloads folder
Time: 2 minutes
```

### STEP 2: Install  
```
1. Double-click osgeo4w-setup-x86_64.exe
2. Click Next > Next > ...
3. At "Libs" tab: Click "Skip" next to:
   - gdal           → shows version (3.7.0)
   - python3-gdal   → shows version (3.7.0)
4. Click Next until Finish
5. Wait for progress bar (5-10 min)
Time: 10 minutes
```

### STEP 3: Verify
```powershell
cd "e:\PYTHON\Radar simulator\bridge_sim_configurable"
python setup_gdal.py --verbose
```
Expected: `✓ SUCCESS: GDAL is ready to use!`  
Time: 1 minute
