RENDERING PIPELINE
======================

ENC File (.000)
    ↓ [GDAL/OGR reads]
ENChart object (22 layers)
    ↓ [Selective load]
enc_layers dict (6 key layers)
    ├─ LNDSRF: [Shapely Polygon objects]
    ├─ DEPCNT: [Shapely LineString objects]
    ├─ COALNE: [Shapely LineString objects]
    ├─ BUOYS:  [Shapely Point objects]
    ├─ LIGHTS: [Shapely Point objects]
    └─ SLCONS: [Shapely LineString objects]
    ↓ [for each geometry in each layer]
Shapely geometry
    ↓ [ll_to_xy() transform]
Screen coordinates (x, y)
    ↓ [pg.draw.* calls]
Pygame rendered to screen


USAGE EXAMPLE
======================

# Load and render ENC in simulator:

from bridge_sim.models import Ship
from bridge_sim.ecdis import ECDISDisplay

ship = Ship(lat=37.0, lon=-76.0, heading=90, speed=10)
ecdis = ECDISDisplay(screen, ship=ship, follow_ship=False)

# Load professional chart
ecdis.load_noaa_enc("bridge_sim/areas/noaa_charts/US5VA18M.000")

# Render every frame
ecdis.draw(ship)


FALLBACK HIERARCHY
======================

When rendering a chart, ECDIS tries in order:

1. ENC vector layers (if load_noaa_enc() was called)
   ├─ Professional vector geometry
   ├─ Color-coded features
   └─ Full detail from NOAA data

2. PNG raster chart (if found in areas/ folder)
   ├─ User-provided image
   ├─ JSON sidecar for georeference
   └─ Scaled to viewport

3. Fallback schematic coastline
   ├─ Hard-coded line segments
   ├─ Always available
   └─ Low detail but functional
